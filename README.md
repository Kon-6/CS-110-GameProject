Problems I Encountered

One problem I had was that GitHub Desktop initially showed 351 changed files. Many of these were unnecessary Unity-generated files.

To fix this, I created and updated my .gitignore file. After making changes, the number of files decreased, and I was able to commit and push my project.

How to Open My Project

1. Download or clone this GitHub repository.
2. Open Unity Hub.
3. Click Add Project from Disk.
4. Select the RollABall folder.
5. Open the project using a compatible version of Unity.
6. Open the saved scene from the Assets folder.
